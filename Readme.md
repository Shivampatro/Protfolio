# 🌌 Nebula Cosmos: Shivam Patro's Portfolio

Welcome to my universe of code! This is my interactive portfolio website, built to showcase full-stack development skills, 3D graphics rendered with WebGL, and complex layout orchestration in a futuristic, space-themed environment.

**[✨ Live Deployment](https://shivam130.vercel.app/)**

---

## 🛰️ Tech Stack

This project leverages cutting-edge web technologies to deliver a fast, performant, and deeply immersive visual experience:

*   **Framework**: [SvelteKit 2](https://kit.svelte.dev/) - For lightweight reactive components and server-side rendering (SSR)
*   **Styling**: SCSS (Sass) - Used safely for robust scaling, theme orchestration, and glassmorphic layouts
*   **3D Graphics**: `ogl` — A lightweight WebGL library used to create 3D Particle Certification maps
*   **Visual Effects**: HTML5 Canvas coordinates map for interactive connective tech branches
*   **Hosting & CI/CD**: [Vercel](https://vercel.com/)

---

## 🛸 Key Features

### 1. **Interactable Nebula Constellation**
A highly performant interactive tech node web made using explicit Canvas contexts. Users can hover individual tech nodes to see visual connections branch dynamically, accompanied by ambient alpha-twinkle nebula glows.

### 2. **Particle Space Certifications Grid**
A visually rich fully immersive 3D grid layout map rendered inside dynamic WebGL points clusters executing lightweight particle buffers natively for smooth desktop support.

### 3. **Galaxy Background Atmosphere**
Smooth, fully buffered transparent alpha WebGL space background loops running iteratively beneath components across layout frames, preserving page load scores.

### 4. **Micro-Interactions & Transitions**
Features lightweight IntersectionObserver hooks on scroll for seamless, fluid animations framing component offsets dynamically.

## 🛠️ Getting Started

To explore this codebase locally, follow these steps:

### ⚙️ Prerequisites
*   [Node.js](https://nodejs.org/) (Recommended: **Node 20+** to guarantee adapter compatibility)
*   `npm`

### 🚀 Setup & Execution

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/Shivampatro/Protfolio.git
    cd Protfolio
    ```

2.  **Install Dependencies**:
    ```bash
    npm install
    ```

3.  **Run Dev Environment**:
    ```bash
    npm run dev
    ```
    _The local server will start playing on `http://localhost:5173/`_

4.  **Local Preview Mode**:
    ```bash
    npm run build
    npm run preview
    ```
